《把工厂变绿》本地主页面原型｜数值校对说明

校对优先级
1. 用户填写的《数值确认表.xlsx》为本轮规则确认来源。
2. 项目、绿色评分与经营公式以用户提供的 HTML 为主。
3. GitHub 仅辅助补充；当前工作区未取得可核对的 GitHub 数值文件，因此没有用 GitHub 补值。
4. 未确认的数据不自行编写。

已采用的 HTML 基准值
- 初始现金 520 万元；初始产能 120 万件/年。
- 不再设置独立项目预算额度；项目直接按完成月数推进并从现金支付。
- 经营现金流沿用 HTML 的营业收入、材料、能源、人工、运维、固定费用、财务费用、所得税和集团上缴公式，年度结果按 1/12 转成月度现金流。
- “招聘能源与 EHS 工程师”的 38 万是每人每年人工成本，月度换算为 38 ÷ 12＝3.1667 万；不是每月扣 38 万。
- 绿色工厂评分沿用五个一级指标、15 个二级指标及市级 60 / 省级 72 / 国家级 84 的认定线。

本轮确认并接入的规则
- 时间从第 1 年 / 2030 年 3 月开始。
- 项目卡直接使用基础完成月数。招聘 1 人后，尚未开工项目按基础月数 × 2/3 向上取整；招聘 2 人后按基础月数 × 1/2 向上取整。
- 多月项目可以安排在不连续月份；累计完成所需月份后即完成，并从季度可选列表移到图鉴。
- 默认阶段收益公式：完整数值成效 × 已施工月数 ÷ 实际完成月数。施工款与数值成效按相同进度逐月发生；资格、认证、前置项目解锁仍在完整完成时发生。
- 扩建产线最多 2 次、招聘最多 2 次、屋顶分布式光伏最多 3 次。
- 首次开工只预核完整项目成本所需现金；推进时按项目工期平均分摊现金支出。
- 绿色信贷保留为真实借款：放款 400 万进入现金并形成同额欠款；8 年内每年还本付息 62 万，月度融资费用为 62÷12，本金按 400÷96 每月减少。
- slot 0 卡牌不再占季度改造月份，统一放入“自由行动－管理事项”，办理后立即完成。
- 厂长压力初始 20；每季度 3 次自由行动；闲聊好感 +5；CG 阈值为 60 和 100。确认表未另定“熟络”阈值，当前原型暂用 60 点关系纪念线识别。
- 摸鱼可逐月重复，成本 0，正常经营现金流照常结算，压力 −10。
- 日常事件采用“季度条数抽取＋月份条件筛选＋候选池加权抽取”：默认 20% 无事件、65% 一条、15% 两条，期望 0.95 条/季度；月份互不重复，因此每月最多一条。日常事件只进入日志，不改变经营、压力或好感。
- 季度经营事件仍在季度末处理。当前 Excel“季度事件”表默认全部停用，不生成未确认经营内容。
- 《游戏数据配置.xlsx》新增“经营时间序列”：可按月覆盖产能、各渠道销量与单价、材料/人工单耗、能源量价、维护/固定/融资费用、所得税率和上缴比例。游戏只读取管理员启用的月份，空白字段回退到动态公式。

补齐的原 HTML 项目卡
- ISO 9001、ISO 14001、ISO 50001、绿色信贷、截图包装、绿电直购扩容、绿证采购、产品能效升级、立体仓储、找关系疏通评审、零碳工厂认证。
- 项目前置关系、成本、可重复上限和完成效果按 HTML 卡牌接入；卡片正文收进详情弹窗，列表仅显示名称、成本、工期与进度。

仍待内容确认

- 本原型不声称已移植完整长期剧情、事件库或全部年度结算边界情况。
